---
name: address-pr-comments
description: Review comments on a pull request URL and address the issues raised.
---

Review the comments on a given pull request URL using the `gh-mcp` (specifically `get_pull_request_comments` or `get_pull_request_reviews`). If MCP tools are unavailable, fallback to the `gh` CLI. Do NOT use the web browser interface to read comments.

Address the issues raised by writing up a plan for each and getting approval before beginning work.
